# NorthStar Dataset

## 📌 Overview

This dataset is designed for analysing operational performance, customer experience, and system-level issues within the NorthStar Urban Mobility and Logistics case study.

It contains multiple interconnected files that simulate real-world logistics and mobility data.

---

## 📂 Dataset Characteristics

The dataset includes:

* Inconsistent categorical values (e.g., zone naming variations)
* Missing values across multiple fields
* Cross-file relationships between customers, orders, deliveries, and incidents
* Hidden operational patterns such as delivery delays and failures
* Customer complaints with compensation and resolution details
* App event data representing user interactions and platform performance

---

## 🔍 Learning Objectives

This dataset allows students to:

* Perform structured querying using **SQL in R**
* Conduct statistical analysis and visualisation in **R**
* Clean data and engineer features using **Python**
* Design and implement **MongoDB Atlas collections** from semi-structured data

---

## ⚠️ Notes

* Data requires preprocessing before analysis
* Some inconsistencies are intentional for learning purposes
* Dataset is suitable for multi-tool integrated analytics workflows
